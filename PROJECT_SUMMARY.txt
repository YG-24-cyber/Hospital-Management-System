================================================================================
                    HOSPITAL MANAGEMENT SYSTEM
                          Project Summary
================================================================================

PROJECT INFORMATION:
--------------------
Project Name: Hospital Management System
Language: C++ (Console-based Application)
Development Environment: Visual Studio Code
Storage: Text file-based (no database)

TECHNICAL SPECIFICATIONS:
-------------------------
- Object-Oriented Programming (OOP)
- Classes: User, Patient, Doctor, Appointment, Billing
- File Handling: Text files for data persistence
- Error Handling: Input validation and error messages
- Modular Design: Separate header and source files

FEATURES IMPLEMENTED:
---------------------
1. User Authentication
   - Login/Logout functionality
   - User registration
   - Role-based access (Admin, Doctor, Patient)

2. Patient Management
   - Add new patients
   - Update patient information
   - Delete patient records
   - Search patients by ID
   - View all patients

3. Doctor/Staff Management
   - Add new doctors
   - Update doctor information
   - Delete doctor records
   - Search doctors by ID
   - View all doctors

4. Appointment Scheduling
   - Schedule appointments (Patient-Doctor)
   - Update appointment details
   - Cancel appointments
   - Search appointments
   - View all appointments

5. Billing and Payment
   - Generate bills (consultation, medicine, tests)
   - Calculate total charges
   - Process payments
   - Generate invoices
   - Track payment status

6. Reporting
   - Patient reports
   - Doctor reports
   - Appointment reports
   - Billing reports

FILE STRUCTURE:
---------------
Source Code:
- main.cpp (Main program with menu system)
- User.h / User.cpp (Authentication)
- Patient.h / Patient.cpp (Patient management)
- Doctor.h / Doctor.cpp (Doctor management)
- Appointment.h / Appointment.cpp (Appointments)
- Billing.h / Billing.cpp (Billing system)

Data Files:
- users.txt (User credentials)
- patients.txt (Patient records)
- doctors.txt (Doctor records)
- appointments.txt (Appointment records)
- bills.txt (Billing records)

Documentation:
- README.md (Complete documentation)
- TESTING_GUIDE.md (Testing instructions)
- QUICK_TEST.md (Quick start guide)

COMPILATION INSTRUCTIONS:
-------------------------
Windows:
  g++ main.cpp User.cpp Patient.cpp Doctor.cpp Appointment.cpp Billing.cpp -o hms.exe

Linux/Mac:
  g++ main.cpp User.cpp Patient.cpp Doctor.cpp Appointment.cpp Billing.cpp -o hms

EXECUTION:
----------
Windows: hms.exe
Linux/Mac: ./hms
